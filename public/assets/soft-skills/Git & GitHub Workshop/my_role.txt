As the Design Head of HYPERSPACE XR SIG, I contributed to the planning and execution of the collaborative Git & GitHub Workshop organized jointly by multiple SIGs at MESWCOE. I had the opportunity to serve as one of the workshop instructors, conducting sessions alongside fellow facilitators and guiding participants through essential Git concepts, GitHub workflows, branching strategies, and collaborative development practices. Through hands-on demonstrations and practical exercises, I helped students build a strong foundation in version control and modern software development workflows.
